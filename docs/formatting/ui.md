# Элементы интерфейса и выделения

## Названия элементов интерфейса

- Названия кнопок, пунктов меню, вкладок, полей и разделов выделяются **полужирным** без кавычек.
- Название пишется точно так же, как в интерфейсе, включая регистр.
- Тип элемента указывайте, только если без него непонятно, о чём речь: «Включите переключатель **Уведомления по почте**».
- Путь по меню записывайте через знак `→`: **Настройки** → **Участники** → **Пригласить**.

!!! failure "Неправильно"
    Нажмите на кнопку "сохранить" в меню 'Настройки'.

!!! success "Правильно"
    В разделе **Настройки** нажмите **Сохранить**.

## Значения в интерфейсе

Названия статусов, ролей и других значений, которые пользователь видит, но не нажимает, пишутся в кавычках-ёлочках: статус «В работе», роль «Менеджер». Если значение нужно выбрать в списке, оно выделяется полужирным, как элемент интерфейса: «В списке **Роль** выберите **Менеджер**».

## Необязательные поля

Если шаг можно пропустить, начните его со слова «Необязательно» и двоеточия: «Необязательно: в поле **Описание** кратко опишите цель проекта». Не добавляйте пометку «(необязательно)» к названию поля: читатель будет искать в интерфейсе поле с таким названием.

## Варианты выбора

Если в шаге нужно выбрать один из нескольких вариантов, опишите варианты вложенным маркированным списком в формате «**Вариант** — описание»:

```markdown
1. В списке **Шаблон** выберите шаблон статусов:
    - **Канбан** — статусы «Новая», «В работе», «Готово»;
    - **Разработка** — статусы «Новая», «В работе», «На проверке», «Готово».
```

## Глаголы для действий в интерфейсе

| Действие | Глагол |
| --- | --- |
| Кнопка, ссылка, значок | нажмите |
| Пункт выпадающего списка, вариант | выберите |
| Флажок, переключатель | включите, отключите |
| Поле ввода | введите, укажите |
| Раздел, вкладка, страница | перейдите, откройте |
| Файл | загрузите, перетащите |

Глагол «кликните» не используется. Глагол «нажмите» подходит и для мыши, и для сенсорного экрана.

## Кнопки без подписи

Если у кнопки есть только значок, назовите её по всплывающей подсказке и укажите значок в скобках: «Нажмите **Фильтр** (значок воронки)».

## Клавиши

Клавиши и сочетания клавиш оформляйте элементом `++…++`: ++ctrl+enter++. Названия клавиш пишутся как на клавиатуре: Ctrl, Shift, Enter.

## Выделения в тексте

| Выделение | Когда используется |
| --- | --- |
| **Полужирный** | Элементы интерфейса. Уровни требований в этом руководстве |
| *Курсив* | Термин при первом упоминании |
| `Моноширинный` | Код, имена файлов, параметры, значения, URL в тексте |

Не выделяйте целые предложения. Не используйте подчёркивание: его путают со ссылкой.

## Примечания и предупреждения

Используйте блоки-примечания:

| Блок | Когда используется |
| --- | --- |
| `!!! note` — Примечание | Полезная дополнительная информация |
| `!!! tip` — Совет | Более удобный способ сделать то же самое |
| `!!! warning` — Внимание | Действие может привести к потере данных или доступа |

В одном разделе — не больше одного блока-примечания. Не кладите в примечание информацию, без которой нельзя выполнить задачу: её пишут в основном тексте.
