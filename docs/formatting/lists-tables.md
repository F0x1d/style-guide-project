# Списки и таблицы

## Когда использовать список

- Нумерованный список — для последовательных шагов, когда порядок важен.
- Маркированный список — для перечислений, когда порядок неважен.
- В списке не меньше двух пунктов.
- Перед списком стоит вводная фраза. Она заканчивается двоеточием, если список продолжает предложение, или точкой, если это самостоятельное предложение.

## Пункты списка

- Пункты одного списка строятся одинаково: все с глагола, все с существительного или все полными предложениями.
- Если пункт — полное предложение, он начинается с прописной буквы и заканчивается точкой.
- Если пункт продолжает вводную фразу, он начинается со строчной буквы и заканчивается точкой с запятой. Последний пункт заканчивается точкой.
- Один шаг инструкции — одно действие. Допустимо объединить два действия в одном экране: «Откройте меню **Проект** и выберите **Настройки**».
- Результат действия пишите отдельным предложением в том же шаге: «Нажмите **Сохранить**. Изменения появятся у всех участников».

!!! failure "Неправильно"
    Доступны форматы:

    - CSV
    - выгрузка в Excel.
    - Можно выгрузить в PDF

!!! success "Правильно"
    Доступны форматы:

    - CSV;
    - XLSX;
    - PDF.

## Вложенность

Не используйте больше двух уровней вложенности списков. Если нужен третий уровень, разбейте документ на разделы.

## Таблицы

- Используйте таблицы для сравнения объектов по одинаковым признакам, для параметров и для справочных данных.
- У таблицы есть шапка. Названия столбцов — существительные с прописной буквы, без точки.
- В ячейке не больше одного-двух предложений. Длинный текст вынесите из таблицы.
- Пустые ячейки не оставляйте: поставьте тире «—».
- Перед таблицей стоит вводная фраза. Не начинайте раздел сразу с таблицы.
- Не используйте таблицы для вёрстки: для размещения текста в колонках или для пошаговых инструкций.
