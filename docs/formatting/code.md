# Код, команды и API

## Код в тексте

- Имена параметров, полей, методов, файлов и значения пишутся моноширинным шрифтом: параметр `project_id`, файл `config.yaml`, значение `true`.
- Не склоняйте и не переводите имена из кода. Если нужно склонение, добавьте родовое слово: «в параметре `limit`», а не «в `limit`-е».

## Блоки кода

- Блоки кода всегда оформляются через тройные обратные кавычки с указанием языка: `bash`, `json`, `python`, `http`.
- Перед блоком кода стоит вводная фраза: что это за код и что с ним делать.
- Пример должен работать при копировании. Не пишите `...` внутри примера, если код от этого перестаёт быть корректным.
- Изменяемые значения пишутся заглавными буквами через подчёркивание и объясняются после блока: `YOUR_API_TOKEN`.
- Не добавляйте в команды приглашение командной строки `$`: кнопка копирования скопирует его вместе с командой.

!!! failure "Неправильно"

    ```
    $ curl https://api.taskbook.example/v1/tasks -H "Authorization: Bearer <токен>"
    ```

!!! success "Правильно"

    ```bash
    curl https://api.taskbook.example/v1/tasks \
      -H "Authorization: Bearer YOUR_API_TOKEN"
    ```

    Вместо `YOUR_API_TOKEN` укажите токен из раздела **Настройки** → **API**.

## Методы API

- Метод API обозначается HTTP-методом и путём: `GET /tasks`, `POST /projects/{project_id}/members`.
- Параметры пути пишутся в фигурных скобках.
- Описание метода начинается с глагола в третьем лице: «Возвращает список задач», «Создаёт проект».
- Параметры запроса и поля ответа описываются в таблице с колонками **Параметр**, **Тип**, **Обязательный**, **Описание**.
- Описание параметра начинается с существительного и не заканчивается точкой, если это одна фраза.
- Дополнительные сведения о параметре пишутся после описания в фиксированном порядке и формате: «Возможные значения: `new`, `in_progress`, `done`. По умолчанию: `20`. Максимум: `100`».
- Если поле ответа может быть пустым, укажите, в каком случае: «`null`, если исполнитель не назначен».
- Типы данных пишутся как в JSON Schema: `string`, `integer`, `boolean`, `array`, `object`.
- Коды ответов записываются числом и названием: `200 OK`, `404 Not Found`.

## Примеры ответов

- Пример ответа приводится в формате JSON с отступом в 2 пробела.
- Данные в примерах — правдоподобные, но выдуманные. Не используйте реальные почтовые адреса, токены и имена клиентов.
- Для адресов используйте домен `example.com`, для API — `api.taskbook.example`.
