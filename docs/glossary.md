# Словарь и глоссарий

## Глоссарий

Термины, которые используются в документации «Таскбука». Один объект называется одним термином.

| Термин | Определение | Не используйте |
| --- | --- | --- |
| Пространство | Рабочая область организации в «Таскбуке». Объединяет проекты и участников | воркспейс, workspace, аккаунт компании |
| Проект | Набор задач с общей целью и общими участниками | доска, борд |
| Задача | Единица работы с исполнителем и сроком | тикет, таск, карточка |
| Подзадача | Задача, вложенная в другую задачу | чайлд, дочерний таск |
| Исполнитель | Участник, который отвечает за выполнение задачи | ассайни, ответственный |
| Участник | Пользователь, у которого есть доступ к пространству или проекту | мембер, член команды |
| Администратор | Участник с правами на управление пространством, оплатой и доступами | админ |
| Статус | Этап, на котором находится задача: «Новая», «В работе», «Готово» | стейт, колонка |
| Токен API | Секретная строка, по которой API узнаёт приложение | ключ, апи-ключ |
| Вебхук | HTTP-запрос, который «Таскбук» отправляет на внешний адрес при событии | хук, веб-хук, callback |

## Словарь написания

Слова, в которых часто ошибаются.

| Правильно | Неправильно |
| --- | --- |
| веб-приложение | вебприложение, web-приложение |
| онлайн | он-лайн, online |
| адрес почты, email | е-мейл, имейл, мыло |
| ID | айди, Id, id (в тексте) |
| JSON | Json, json (в тексте) |
| офлайн | оффлайн |
| логин (имя пользователя) | логин (в значении «вход») |
| интернет | Интернет |
| чек-лист | чеклист, чек лист |
| срок | дедлайн |
