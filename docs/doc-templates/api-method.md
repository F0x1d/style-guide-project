# Шаблон: описание метода API

Описание метода API нужно разработчику, который пишет интеграцию с «Таскбуком». Оно отвечает на вопросы: что делает метод, как его вызвать и что он вернёт.

## Структура

1. Заголовок — HTTP-метод и путь: «Метод GET /tasks».
1. Описание — что делает метод, одним-двумя предложениями в третьем лице.
1. Запрос — URL, заголовки, параметры пути и запроса, тело запроса.
1. Пример запроса — на `curl`.
1. Ответ — поля ответа и пример ответа.
1. Ошибки — коды ответов и причины.

## Шаблон

Скопируйте шаблон в новый файл и замените текст в квадратных скобках.

````markdown
# Метод [HTTP-метод] [/путь]

[Глагол в третьем лице: «Возвращает…», «Создаёт…».] [Ограничения и особенности.]

## Запрос

```http
[HTTP-метод] https://api.taskbook.example/v1/[путь]
Authorization: Bearer YOUR_API_TOKEN
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| `[имя]` | `[тип]` | Да | [Описание. Значение по умолчанию.] |

### Пример запроса

```bash
curl [URL] \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

## Ответ

| Поле | Тип | Описание |
| --- | --- | --- |
| `[имя]` | `[тип]` | [Описание] |

### Пример ответа

```json
{
  "[поле]": "[значение]"
}
```

## Ошибки

| Код | Причина |
| --- | --- |
| `401 Unauthorized` | Токен не передан или недействителен |
````
