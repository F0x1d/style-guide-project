# Тон и обращение к читателю

## Тон документации

Документация «Таскбука» звучит как спокойный и компетентный коллега: объясняет по делу, не заигрывает с читателем и не давит на него.

- Пишите нейтрально и доброжелательно.
- Не используйте шутки, мемы, сленг и эмодзи.
- Не оценивайте сложность задачи за читателя: слова «просто», «легко», «всего лишь», «очевидно» не используются. То, что легко автору, может быть трудно читателю.
- Не используйте рекламные формулировки: «уникальный», «революционный», «лучший на рынке».

!!! success "Правильно"

## Обращение к читателю

- Обращайтесь к читателю на «вы». «Вы» пишется со строчной буквы.
- В инструкциях используйте повелительное наклонение: «нажмите», «укажите», «выберите».
- Не используйте слово «пожалуйста» в шагах инструкции. Оно допустимо только в сообщениях об ошибках, когда пользователь должен подождать или повторить действие.
- Не пишите от первого лица единственного числа («я рекомендую»). О компании и команде пишите «мы»: «Мы храним резервные копии 30 дней».

| Тип документа | Особенности тона |
| --- | --- |
| Инструкция | Короткие повелительные предложения, без вступлений |
| Справочник API | Безличные конструкции: «Метод возвращает…», «Параметр задаёт…» |
| Описание изменений | Описывайте пользу для читателя: «Теперь можно…» |
| Сообщение об ошибке | Объясните, что произошло и что сделать дальше. Не обвиняйте пользователя |
