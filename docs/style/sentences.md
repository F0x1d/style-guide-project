# Построение предложений

## Длина предложений и абзацев

- **Рекомендуется:** не более 20 слов в предложении. Длинное предложение разделите на два.
- Одно предложение — одна мысль.
- В абзаце не более 4–5 предложений. Абзац раскрывает одну тему.

## Действительный залог

Используйте действительный залог. Страдательный залог скрывает, кто выполняет действие.

!!! failure "Неправильно"
    Доступ к проекту может быть предоставлен администратором.

!!! success "Правильно"
    Администратор может открыть доступ к проекту.

Страдательный залог **допустим**, когда исполнитель неважен или неизвестен: «Файл загружен».

## Канцелярит

Не используйте канцелярские обороты. Они удлиняют текст и не добавляют смысла.

| Вместо | Пишите |
| --- | --- |
| данный проект | этот проект |
| осуществить настройку | настроить |
| является обязательным | обязателен |
| в целях обеспечения безопасности | чтобы защитить данные |
| посредством API | через API |
| производится отправка | отправляется |
| на сегодняшний день | сейчас |
| в случае если | если |

Отглагольные существительные заменяйте глаголами: не «выполнение сохранения», а «сохраните».

## Порядок слов

- Начинайте с цели или условия, затем указывайте действие: «Чтобы пригласить участника, нажмите **Пригласить**».
- Важное — в начале предложения. Читатель часто читает только первые слова.

!!! failure "Неправильно"
    Нажмите **Пригласить**, если хотите добавить в проект нового участника.

!!! success "Правильно"
    Чтобы добавить участника в проект, нажмите **Пригласить**.

## Вводные слова и слова-паразиты

Удаляйте слова, которые не несут смысла: «собственно», «в принципе», «как бы», «так сказать», «вообще», «на самом деле».

## Отрицания

Формулируйте утвердительно. Двойные отрицания запрещены.

!!! failure "Неправильно"
    Нельзя не указать название проекта.

!!! success "Правильно"
    Укажите название проекта.
