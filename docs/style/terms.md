# Терминология и иноязычные слова

## Единство терминов

- Один объект — один термин во всей документации. Синонимы для разнообразия не используются.
- Используйте термины из [словаря](../glossary.md). Если термина там нет, добавьте его в словарь в том же pull request.
- При первом упоминании редкого термина дайте определение или ссылку на глоссарий.

!!! failure "Неправильно"
    Создайте задачу. Тикет появится в списке. Откройте таск и назначьте исполнителя.

!!! success "Правильно"
    Создайте задачу. Задача появится в списке. Откройте задачу и назначьте исполнителя.

## Название продукта

- Название сервиса пишется по-русски в кавычках-ёлочках: «Таскбук». Склоняется как существительное мужского рода: «в «Таскбуке», «для «Таскбука».
- Латинское написание Taskbook используется только в коде, URL и названиях пакетов.
- Названия тарифов пишутся с прописной буквы без кавычек: тариф Бизнес, тариф Старт.

## Иноязычные слова

1. Если есть устоявшийся русский эквивалент, используйте его: «вход», а не «логин»; «настройки», а не «сеттинги».
1. Устоявшиеся заимствования пишутся кириллицей: «браузер», «сервер», «токен», «вебхук».
1. Названия сторонних продуктов, протоколов и стандартов пишутся в оригинальном написании без кавычек: GitHub, Slack, OAuth 2.0, JSON, REST API.
1. Названия технологий не склоняются и не переводятся.

## Аббревиатуры

- При первом упоминании аббревиатуру расшифровывают: «единый вход (SSO)». Общеизвестные аббревиатуры (API, URL, HTTP, JSON, ID) не расшифровываются.
- Аббревиатуры не склоняются с окончаниями через дефис: не «API-шка», не «URL-а».
