# Создать проект

Проект объединяет задачи с общей целью и участников, которые над ними работают. После создания проекта можно добавить в него задачи и пригласить участников.

## Перед началом

- Создавать проекты могут администраторы и участники с ролью «Менеджер».
- На тарифе Старт в пространстве может быть не больше трёх проектов.

## Создать проект

1. На боковой панели нажмите **Новый проект** (значок плюса).
1. В поле **Название** введите название проекта. Название должно быть не длиннее 100 символов.
1. Необязательно: в поле **Описание** кратко опишите цель проекта.
1. В списке **Шаблон** выберите шаблон статусов:
    - **Канбан** — статусы «Новая», «В работе», «Готово»;
    - **Разработка** — статусы «Новая», «В работе», «На проверке», «Готово».
1. Чтобы проект видели только приглашённые участники, включите переключатель **Закрытый проект**.
1. Нажмите **Создать**.

Проект появится на боковой панели в разделе **Проекты**. Вы станете его владельцем.

!!! note "Примечание"
    Шаблон статусов можно изменить позже в разделе **Настройки проекта** → **Статусы**.
