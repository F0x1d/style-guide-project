# Руководство по стилю документации «Таскбук»

Руководство по стилю для пользовательской и API-документации условного SaaS-сервиса управления задачами «Таскбук». Репозиторий ведётся по методологии Docs as Code: правила хранятся в Markdown, проверяются линтерами и автоматически публикуются на GitHub Pages.

Сайт руководства: <https://f0x1d.github.io/style-guide-project/>

## Состав репозитория

| Путь | Содержимое |
| --- | --- |
| `docs/` | Разделы руководства в Markdown |
| `docs/examples/` | Документы, написанные по руководству. Проверяются Vale |
| `mkdocs.yml` | Настройки сайта и навигация |
| `.markdownlint.yaml` | Правила markdownlint |
| `.vale.ini`, `styles/Taskbook/` | Правила Vale, которые проверяют текст по руководству |
| `.github/workflows/docs.yml` | CI/CD: линтинг, сборка и деплой на GitHub Pages |
